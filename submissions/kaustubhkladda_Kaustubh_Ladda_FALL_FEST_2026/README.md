## Problem Statement

Predict logical bit flips from quantum error correction syndrome measurements and compare different decoding approaches.

## Proposed Approach

1. Minimum Weight Perfect Matching (MWPM)
2. Multilayer Perceptron (MLP)
3. MOR adaptive decoder router

The passive and actively corrected repetition code circuits will also be tested on real IBM Quantum hardware.
